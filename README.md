# Social Downloader by WARISS — Releases

Official public release repository for **Social Downloader by WARISS**, a Windows desktop downloader for YouTube, TikTok, Instagram, and Facebook.

## Download

Go to **Releases** and download the latest Windows standalone EXE.

The application is designed for a simple end-user setup:

- No Python required
- No pip required
- No CMD setup required
- No manual dependency installation required
- Required runtime components are bundled with the application

## Updates

The application includes a built-in update checker. New versions are published here and can be detected from inside the app.

## Security

Release files are accompanied by SHA-256 checksums where available. Do not download or run modified builds from unofficial sources.

## Source

The application source and build pipeline are maintained separately in the private development repository.
